# Instalasi 26 Motor Premium Android

Untuk Android 10 atau lebih baru.

1. Pastikan aplikasi bengkel berjalan di komputer server.
2. Hubungkan HP ke jaringan yang sama atau jaringan yang dapat mengakses server.
3. Unduh APK dari komputer, atau buka alamat berikut dari browser HP:
   http://192.168.1.7:3000/downloads/26motor-premium.apk
4. Buka file APK di HP dan ikuti proses pemasangan Android.
5. Buka aplikasi 26 Motor Premium. Isi alamat server:
   http://192.168.1.7:3000
6. Tekan Hubungkan ke Server dan login menggunakan akun bengkel yang sudah ada.

Alamat di atas merupakan alamat komputer saat panduan dibuat pada 16 Oktober 2026 dan bisa berubah jika konfigurasi jaringan berubah. Jangan memakai 127.0.0.1 di HP untuk menunjuk komputer.

## Pemakaian
- Menu Aksi menampilkan tindakan sesuai hak akses akun.
- Pekerjaan membuka Work Order, progres, teknisi, dan QC.
- Stok membuka persediaan, penerimaan, dan aksi sparepart.
- Menu membuka seluruh fitur dan dashboard yang diizinkan.
- Preview PDF estimasi, invoice, dan Gate Pass dapat dibuka sebelum diunduh.
- PDF, Excel per baris/tabel, dan CSV laporan disimpan ke Download/26Motor.
- Pasang pembaruan APK 1.1.0 untuk mendukung unduhan Excel.
- Cetak Gate Pass membuka dialog cetak Android.
- Tombol Server di bagian atas mengganti alamat koneksi.

Komputer server harus tetap menyala. Transaksi memerlukan koneksi aktif ke server; data akun dan transaksi mengikuti aplikasi bengkel, tanpa database terpisah di APK. Untuk koneksi dari internet, gunakan server HTTPS dengan sertifikat valid. Jika koneksi gagal, periksa alamat, Wi-Fi, server yang aktif dan pengaturan akses jaringan komputer.

APK internal telah dibangun dan tanda tangannya diverifikasi. Tampilan mobile telah diperiksa di browser ukuran 320 dan 390 piksel. Pengujian pemasangan serta pemakaian pada HP Android fisik belum dilakukan.
